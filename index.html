04 採掘・購入材料 RAW

エネルギーセルは生産ウェアだが、ほぼ全ウェアの生産で消費されるため、例外として消費分を材料費に含める(目標として生産する分は除く)。

05 必要生産モジュール

建設費用は必要基数の切り上げ × 1基あたり建設素材 × 単価(価格記載分のみ)。一部素材が未記載のモジュールは概算で「*」を付す。

06 建設素材 / Construction Materials

各生産モジュールを建てるのに必要な建設素材の総量(必要基数の切り上げ × SEED の build)。素材に avgPrice があれば概算費用も表示。

07 収益性 / Economics

SEED に avgPrice / volume を記載した全ウェアを表示(目標とは独立)。生産量/h・価値/h は 1 基(outputRate)あたり。体積あたり価値 = 平均価格 ÷ 体積。列見出しクリックで昇順 / 降順ソート。

01 生産フロー / Dependency Map
採掘・購入 (RAW) 生産ウェア 左 = 素材 / 右 = 加工品 ・ ノードにカーソルを合わせると依存を強調
01 セクター資源 / Sector Resources

セクターごとの採掘資源量。データはコード内 SECTORS を直接編集する(SEED と同じ運用)。 数値 = 実測 yield / 0 = 資源なし / — = 未調査。列見出しクリックで昇順 / 降順ソート。
